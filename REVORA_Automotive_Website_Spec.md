# REVORA --- Automotive Care Platform

> **Your Car. Fully Refined.**

A premium, cinematic automotive detailing and service platform designed
as a portfolio/demo website. REVORA helps car owners discover automotive
specialists, compare service packages, and schedule appointments.

------------------------------------------------------------------------

## 1. Project Overview

### Brand

**Name:** REVORA\
**Category:** Automotive Detailing & Service Platform\
**Tagline:** Your Car. Fully Refined.\
**Market:** Premium automotive care\
**Primary Currency:** INR (₹)

### Concept

REVORA combines the visual quality of a premium automotive brand with
the functionality of a modern service-booking platform.

Instead of behaving like a traditional garage website, REVORA should
feel like a digital automotive experience where users can:

-   Discover automotive services
-   Browse detailing and maintenance packages
-   Find service centers
-   Compare packages
-   View specialist profiles
-   Add and manage vehicles
-   Schedule appointments
-   Receive service reminders
-   Book mobile detailing
-   Explore membership plans

### Design Goal

The website should demonstrate strong:

-   Visual design
-   Typography
-   Responsive layout
-   UX architecture
-   Service discovery
-   Booking UX
-   Scroll storytelling
-   Parallax animation
-   Interactive cards
-   Dashboard design
-   Automotive art direction

# 3. Visual Direction

## Overall Style

**Premium Automotive + Modern Digital Product**

Visual references should feel closer to:

-   Luxury automotive advertising
-   Premium automotive configurators
-   High-end editorial websites
-   Modern SaaS interfaces
-   Cinematic product launches

### Color System

#### Primary

-   Near Black: `#0B0B0B`
-   Charcoal: `#151515`
-   Dark Surface: `#1D1D1D`
-   Warm White: `#F4F2ED`
-   Muted Gray: `#A4A4A0`

#### Accent

Use a restrained electric lime:

-   Accent: `#C8F31D`

The accent should be used primarily for:

-   Primary buttons
-   Active states
-   Small highlights
-   Availability indicators
-   Important UI details

### Typography

Use a modern geometric or grotesk sans-serif.

Recommended direction:

-   Headings: bold / extra-bold
-   Body: regular / medium
-   Labels: medium / uppercase
-   Numbers: bold

### Typography Scale

-   Display: 80--120px
-   H1: 64--80px
-   H2: 48--64px
-   H3: 28--36px
-   Body: 16--20px
-   Small: 12--14px
-   Labels: 11--13px

Responsive typography should scale down smoothly on tablets and mobile.

# 30. Motion Principles

All animation should follow these rules:

1.  Slow rather than fast
2.  Smooth rather than flashy
3.  Purposeful rather than decorative
4.  Use motion to establish hierarchy
5.  Keep text readable
6.  Avoid excessive simultaneous animations
7.  Maintain performance
8.  Support reduced-motion preferences

### Reduced Motion

If the user prefers reduced motion:

-   Disable parallax
-   Disable large transforms
-   Remove auto zoom effects
-   Keep simple fades
-   Preserve all content and functionality

# 41. Google Stitch Generation Direction

When generating the website in Google Stitch, prioritize:

1.  Establish the visual system first.
2.  Generate the homepage as a complete experience.
3.  Generate the service directory separately.
4.  Generate the service detail page.
5.  Generate the booking flow.
6.  Generate the My Garage dashboard.
7.  Connect the visual language across every screen.
8.  Add scroll-driven/parallax behavior during iteration.
9.  Test desktop and mobile layouts.
10. Refine spacing, typography, imagery, and interaction states.

### Stitch Prompt Addition

Use this instruction when asking Stitch to create the visual experience:

> "Design this as a cinematic scroll-driven automotive website. Use
> layered imagery, sticky visual sections, subtle parallax, progressive
> content reveals, oversized typography, and smooth transitions. The
> animation should feel premium and restrained, similar to a high-end
> automotive campaign website. Prioritize usability and readability over
> decorative animation."

## REVORA
